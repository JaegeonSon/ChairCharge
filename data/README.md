# Data

## 폴더 설명

- `raw`: 원본 압축파일 및 원본 데이터 보관
- `processed`: 앱/서버 개발용 정제 데이터 보관

## 주요 파일

- `chargers_gunsan_app.json`: 앱 지도 마커용 데이터
- `chargers_gunsan_app.csv`: 앱/서버용 CSV
- `chargers_gunsan_master.csv`: 통합 마스터 데이터
- `chargers_gunsan_issues.csv`: 검토 필요 항목
- `chargers_gunsan.sqlite`: 테스트용 SQLite DB
