# WheelCharge

> 전동휠체어 이용자를 위한 군산시 충전소 위치 안내 및 공공데이터 기반 접근성 추천 서비스

## 문제의식

전동휠체어 이용자는 충전소의 위치뿐 아니라 목적지까지의 거리, 도로
횡단 환경, 지형 부담, 시설 정보의 충분성까지 함께 확인해야 합니다.
WheelCharge는 흩어진 공공데이터를 충전소 단위로 결합해 이용자가
이동 전에 접근성을 비교하고 판단할 수 있도록 돕습니다.

## 현재 MVP 핵심 기능

- 군산시 전동휠체어 충전소 지도 표시
- 현재 위치 기준 가까운 충전소 TOP 5 추천
- 시설명, 주소, 설치 위치, 문의처 등 충전소 상세정보 제공
- 횡단보도·보도턱 낮춤·점자블록·보행자신호 정보 제공
- 브이월드 DEM 기반 고도·경사 위험도 정보 제공
- 다섯 평가 항목을 합산한 통합 100점 접근성 점수와 추천 등급 제공
- 점수 구성과 추천 사유를 통한 추천 근거 설명
- TMAP 계단 제외 우선 보행자 경로와 실패 시 직선 Polyline fallback
- 횡단보도 지도 레이어 ON/OFF
- FastAPI 서버 연결 실패 시 Android assets의 로컬 JSON fallback

TMAP 보행자 경로 호출에 실패하거나 유효한 경로 좌표가 없으면 현재
위치와 충전소를 연결하는 위치 확인용 직선 Polyline을 표시합니다.

## TMAP API Key 설정

Android Studio의 `android/local.properties`에 다음 값을 설정합니다.

```properties
TMAP_APP_KEY=발급받은_TMAP_APP_KEY
```

`local.properties`는 Git 제외 대상이며 실제 키를 문서나 소스에 기록하지
않습니다. 본 MVP에서는 시연 편의성을 위해 Android 앱에서 TMAP 보행자
경로 REST API를 직접 호출합니다. 실제 서비스 배포 단계에서는 API Key
보호를 위해 서버 프록시 방식으로 전환하는 것이 바람직합니다.

## 통합 접근성 점수

| 평가 항목 | 배점 |
|---|---:|
| 거리 접근성 | 30점 |
| 충전소 정보 완성도 | 20점 |
| 횡단보도 접근성 | 20점 |
| 경사도/고도 안전성 | 20점 |
| 이용 편의성 | 10점 |
| 합계 | 100점 |

추천 등급은 85점 이상 **적극 추천**, 70점 이상 **이용 추천**,
55점 이상 **확인 후 이용**, 55점 미만 **이용 전 주의**입니다.
점수는 현장 안전을 보장하는 값이 아니라 이동 전 비교를 돕는
규칙 기반 참고 지표입니다.

자세한 산식과 해석 기준은
[접근성 점수 모델](docs/ACCESSIBILITY_MODEL.md)에서 확인할 수 있습니다.

## 사용 공공데이터

- 군산시 전동휠체어 충전소 위치 및 시설 정보
- 전북특별자치도 횡단보도 현황 중 군산시 데이터
- 브이월드 한반도 DEM 90m 기반 고도·경사도 추정 데이터

보행자전용도로 데이터는 국토교통부 도시계획정보 SHP를 검토했으나
군산시 행정코드 기준 제공분이 확인되지 않았습니다. 데이터 가용성
검토 결과 이번 MVP의 앱 UI와 점수에서는 제외하고 향후 확장 항목으로
분류했습니다.

데이터 출처와 가공 과정은
[공공데이터 활용 정리](docs/DATA_SOURCES.md)에 기록했습니다.

## 기술 스택

- Android Kotlin, Jetpack Compose
- Kakao Map SDK v2
- TMAP 보행자 경로 REST API
- FastAPI
- Python 데이터 가공
- GeoJSON, JSON
