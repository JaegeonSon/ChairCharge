# WheelCharge 공공데이터 출처와 가공

## 1. 데이터 활용 개요

WheelCharge는 충전소 위치 정보에 횡단보도와 지형 정보를 결합해
전동휠체어 이용자가 이동 전에 접근성을 비교할 수 있도록 구성했습니다.

| 데이터 | 출처 | 원본 형식 | 앱 반영 |
|---|---|---|---|
| 전동휠체어 충전소 | 군산시 충전소 위치·시설 정보 | JSON 등 구조화 데이터 | 마커, 상세정보, TOP 5 |
| 횡단보도 | 전북특별자치도 횡단보도 현황 | SHP | 접근성 점수, 상세정보, 지도 레이어 |
| 고도·경사도 | 브이월드 한반도 DEM 90m | DEM 래스터 | 경사 안전성 점수, 상세정보 |
| 보행자전용도로 | 국토교통부 도시계획정보 | SHP | 가용성 검토 후 MVP 제외 |

## 2. 전동휠체어 충전소 데이터

### 활용 목적

- 군산시 충전소 지도 마커 표시
- 현재 위치 또는 테스트 위치 기준 가까운 충전소 TOP 5 산출
- 시설명, 주소, 설치 위치, 문의처 등 상세정보 제공
- 충전소 정보 완성도와 이용 편의성 점수 계산

### 가공 내용

- 시설명과 주소 표기 정리
- 위도·경도 숫자 형식 정규화
- 설치 위치, 설치 구분, 문의처 필드 정리
- 실내·옥외·이동식 충전기 여부 정규화
- 서버 API와 Android 로컬 fallback에서 같은 Charger 구조 사용

### 앱 반영 방식

정상 연결 시 FastAPI에서 데이터를 불러옵니다. 서버 연결에 실패하면
Android assets의 충전소 JSON을 읽어 지도, TOP 5, 상세정보 기능을
유지합니다.

## 3. 횡단보도 데이터

### 출처와 원본

- 데이터: 전북특별자치도 횡단보도 현황 제공
- 원본 형식: SHP
- 필터 조건: 시군구명이 군산시인 데이터
- 가공 결과: 군산시 횡단보도 3,989건

### 가공 내용

- 좌표를 앱에서 사용할 수 있는 위도·경도로 변환
- 보행자신호, 보도턱 낮춤, 점자블록, 고원식 횡단보도 값을
  boolean 형태로 정규화
- 충전소별 주변 횡단보도 개수와 최근접 횡단보도 거리 계산
- 충전소별 보도턱 낮춤, 점자블록, 보행자신호 개수 집계
- Android용 GeoJSON과 충전소별 context JSON 생성

### 앱 반영 방식

- 통합 점수의 횡단보도 접근성 항목 20점에 반영
- 상세정보 패널에서 충전소 주변 집계 정보 제공
- 지도에서 횡단보도 표시 토글 제공
- 성능 보호를 위해 레이어는 기본 OFF이며, 표시 시 기준점 주변
  1km 이내 최대 250개를 시각화

## 4. 고도·경사도 데이터

### 출처와 원본

- 데이터: 브이월드 한반도 DEM
- 공간 해상도: 90m
- 원본 형식: DEM 래스터

### 가공 내용

- 각 충전소 좌표의 고도 샘플링
- 충전소 주변 5×5 DEM 셀의 고도차를 이용해 경사도 추정
- 추정 결과를 낮음·보통·높음의 경사 위험도로 분류
- 충전소별 고도, 경사율, 경사각, 경사 위험도 context 생성

### 앱 반영 방식

- 경사 위험도를 통합 점수의 경사도/고도 안전성 20점에 반영
- 고도와 경사 추정값을 충전소 상세정보에 표시
- 고도 자체는 점수에 직접 가산하지 않음

DEM 기반 값은 실제 보도 단위 측량값이 아니므로 현장 경사와 차이가
있을 수 있습니다.

## 5. 충전소별 데이터 결합

가공된 `charger_accessibility_context_gunsan.json`을 우선 활용하며
다음 순서로 충전소와 context를 연결합니다.

1. 충전소 고유 ID
2. 시설명과 주소 조합
3. 75m 이내 좌표 근접 매칭

매칭되지 않거나 일부 데이터가 없는 경우 앱이 중단되지 않도록
통합 점수의 데이터 누락 기본값을 적용합니다. 원본 context에 남아
있는 과거 보너스 값은 현재 통합 점수에 사용하지 않습니다.

## 6. 보행자전용도로 데이터 검토 결과

국토교통부 도시계획정보 보행자전용도로 `C_UQ164_RO` SHP를 검토하고
군산시 행정코드 후보 45130, 52130을 확인했으나 군산시 제공분은
확인되지 않았습니다.

이는 데이터 활용의 실패가 아니라 **데이터 가용성 검토 결과에 따른
범위 결정**입니다. 다른 지역 데이터를 군산시 데이터로 간주하지
않고, 이번 MVP의 앱 UI와 접근성 점수에서는 제외했습니다. 사용자
화면에도 데이터 부재 문구를 노출하지 않습니다.

향후 보행자도로, 인도 폭, 보도 단절 정보가 추가 개방되면 실제 이동
연속성과 우회 부담을 평가하는 항목으로 확장할 수 있습니다.

## 7. 향후 확장 데이터

| 데이터 | 확장 활용 방향 |
|---|---|
| 보행자도로·인도 폭·보도 단절 | 이동 가능한 보행 네트워크와 단절 구간 분석 |
| 보호구역 | 저속 운행 및 안전 환경 참고 |
| 장애인 편의시설 | 이동 중 이용 가능한 편의시설 안내 |
| 기상청 단기예보 | 비·눈·폭염 등 시간대별 이동 부담 반영 |
| 사용자 신고·리뷰 | 공사, 장애물, 고장 등 현장 정보 보완 |

이 데이터는 현재 앱 점수에 반영되지 않았으며, 확보·품질 검증 후
향후 접근성 모델과 AI 추천 모델 고도화에 활용할 수 있습니다.
