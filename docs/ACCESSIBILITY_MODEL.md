# WheelCharge 접근성 점수 모델

## 1. 모델 목적

WheelCharge 접근성 점수는 전동휠체어 이용자가 충전소를 선택할 때
비교·참고할 수 있도록 만든 **100점 만점의 규칙 기반 지표**입니다.

현재 MVP는 실제 보행 경로 전체를 분석하지 않습니다. 충전소 위치와
기준 위치 사이의 직선거리, 충전소 기본 정보, 주변 횡단보도 환경,
DEM 기반 경사 위험도, 이용 편의 정보를 충전소 단위로 결합해 1차
접근성 점수를 계산합니다.

> 접근성 점수는 공공데이터와 충전소 정보를 기반으로 계산한 참고
> 지표이며, 실제 현장 상황, 공사, 장애물, 도로 상태와 차이가 있을 수
> 있습니다.

## 2. 설계 원칙

- 총점은 다섯 항목의 합계로 설명할 수 있어야 합니다.
- 별도의 기본 점수나 공공데이터 보너스를 더하지 않습니다.
- 데이터 누락만으로 과도한 불이익이 생기지 않도록 일부 항목에
  중립적인 기본값을 적용합니다.
- TOP 5 카드와 상세정보는 동일한 계산 결과를 사용합니다.
- 현재 위치가 있으면 현재 위치를, 없으면 군산시청 인근 테스트
  위치를 거리 기준으로 사용합니다.

## 3. 점수 구성

| 평가 항목 | 배점 | 평가 목적 |
|---|---:|---|
| 거리 접근성 | 30점 | 충전소까지의 이동 부담 |
| 충전소 정보 완성도 | 20점 | 위치 확인과 사전 문의 가능성 |
| 횡단보도 접근성 | 20점 | 도로 횡단 환경 참고 |
| 경사도/고도 안전성 | 20점 | 지형에 따른 이동 부담 참고 |
| 이용 편의성 | 10점 | 실내·이동식 충전기 편의 |
| 합계 | 100점 | 통합 접근성 참고 지표 |

### A. 거리 접근성: 30점

현재 위치 또는 테스트 기준 위치에서 충전소까지의 직선거리로
계산합니다.

| 직선거리 | 점수 |
|---|---:|
| 500m 이하 | 30점 |
| 1km 이하 | 25점 |
| 2km 이하 | 18점 |
| 3km 이하 | 10점 |
| 3km 초과 | 5점 |
| 계산 불가 | 10점 |

거리 계산 불가는 데이터 누락만으로 0점이 되지 않도록 10점을
적용합니다. 향후 실제 보행 경로 API를 연동하면 직선거리 대신 경로
거리와 예상 이동 부담을 반영할 수 있습니다.

### B. 충전소 정보 완성도: 20점

| 정보 | 점수 |
|---|---:|
| 주소 정보 | 5점 |
| 설치 위치 설명 | 8점 |
| 문의처 | 7점 |

빈 값, 정보 없음, 없음, 하이픈과 같은 값은 정보가 없는 것으로
판정합니다. 이 항목은 충전소를 실제로 찾고 이용 전에 운영 상태를
확인할 수 있는지를 평가합니다.

### C. 횡단보도 접근성: 20점

| 정보 | 점수 |
|---|---:|
| 반경 내 횡단보도 1개 이상 | 5점 |
| 가장 가까운 횡단보도 100m 이내 | 5점 |
| 가장 가까운 횡단보도 150m 이내 | 4점 |
| 가장 가까운 횡단보도 300m 이내 | 2점 |
| 보도턱 낮춤 1개 이상 | 4점 |
| 점자블록 1개 이상 | 3점 |
| 보행자신호 1개 이상 | 3점 |

가장 가까운 횡단보도 거리 점수는 하나의 구간만 적용합니다. 횡단보도
context가 없으면 데이터 누락에 대한 중립값으로 6점을 적용합니다.

### D. 경사도/고도 안전성: 20점

브이월드 DEM 기반 추정 경사 위험도를 사용합니다.

| 경사 위험도 | 점수 |
|---|---:|
| 낮음 | 20점 |
| 보통 | 12점 |
| 높음 | 4점 |
| 정보 없음 | 8점 |

고도 값은 상세정보에 표시하지만 점수에 직접 더하지 않습니다.
DEM은 90m 해상도 기반 추정치이므로 실제 보도 단위 경사와 차이가
있을 수 있습니다.

### E. 이용 편의성: 10점

| 정보 | 점수 |
|---|---:|
| 실내 충전소 | 5점 |
| 이동식 충전기 | 5점 |

옥외 여부는 상세정보로만 제공하며 가점하지 않습니다.

## 4. 추천 등급

| 총점 | 추천 등급 | 해석 |
|---|---|---|
| 85점 이상 | 적극 추천 | 현재 데이터 기준 접근성이 우수 |
| 70점 이상 85점 미만 | 이용 추천 | 전반적으로 이용을 추천 |
| 55점 이상 70점 미만 | 확인 후 이용 | 일부 조건을 사전에 확인 |
| 55점 미만 | 이용 전 주의 | 이동 경로와 현장 조건 확인 필요 |

추천 사유는 거리, 횡단보도, 경사 위험도, 정보 완성도, 이용 편의성
순으로 핵심 내용을 선별해 3~5개 문장으로 제공합니다.

## 5. 현재 모델의 한계

- 지도에 표시되는 선은 실제 보행 경로가 아닌 직선 연결입니다.
- 공사, 적치물, 보도 파손, 임시 장애물은 반영하지 못합니다.
- DEM 기반 경사는 실제 이동 경로의 세부 경사와 다를 수 있습니다.
- 점수는 안전을 보장하거나 전문가의 현장 판단을 대체하지 않습니다.
- 머신러닝 모델은 현재 구현하지 않았습니다.

## 6. 향후 고도화 방향

- 실제 보행 경로 거리와 위험 구간 반영
- 인도 폭, 보도 단절, 노면 상태 데이터 반영
- 보호구역, 장애인 편의시설, 기상 데이터 결합
- 사용자 신고와 이용 후기를 통한 현장 정보 보완
- 사용자 이동 특성을 반영한 AI 추천 모델 연구
