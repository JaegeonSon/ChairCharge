# WheelCharge 프로젝트 요약

## 1. 서비스 개요

| 구분 | 내용 |
|---|---|
| 서비스명 | WheelCharge |
| 한 줄 소개 | 전동휠체어 이용자를 위한 군산시 충전소 위치 안내 및 공공데이터 기반 접근성 추천 서비스 |
| 대상 사용자 | 전동휠체어 이용자, 고령자, 이동약자 |
| 현재 서비스 지역 | 군산시 |
| 개발 단계 | Android MVP |

## 2. 해결하고자 하는 문제

충전소 위치가 공개되어 있어도 전동휠체어 이용자가 실제로 접근하기
쉬운지는 별도로 판단하기 어렵습니다. 가까운 충전소라도 도로 횡단
환경이나 경사, 시설 정보 부족으로 이동 부담이 커질 수 있습니다.

WheelCharge는 충전소 위치와 주변 이동 환경 데이터를 함께 제공해
“충전소가 어디에 있는가”뿐 아니라 “어느 충전소를 선택할 것인가”를
판단하도록 돕습니다.

## 3. 핵심 기능

- 군산시 충전소 지도 및 상세정보
- 현재 위치 기반 가까운 충전소 TOP 5
- TOP 5 카드와 지도 마커의 선택 상태 연동
- 횡단보도와 경사도·고도 기반 접근성 정보
- 통합 100점 접근성 점수, 4단계 추천 등급, 추천 사유
- 항목별 점수 breakdown을 통한 추천 근거 설명
- 현재 위치와 충전소 사이의 위치 확인용 직선 Polyline
- 횡단보도 지도 레이어
- FastAPI 서버와 Android 로컬 JSON fallback

## 4. 사용 공공데이터

| 데이터 | 활용 |
|---|---|
| 군산시 전동휠체어 충전소 | 마커, 상세정보, 가까운 충전소 추천 |
| 전북특별자치도 횡단보도 현황 | 횡단보도 접근성 점수와 지도 레이어 |
| 브이월드 DEM 90m | 고도 표시와 경사 위험도 점수 |

보행자전용도로 데이터는 가용성을 검토했으나 군산시 행정코드 기준
제공분이 확인되지 않아 이번 MVP의 UI와 점수에서 제외했습니다.

## 5. 알고리즘 요소

현재 MVP는 머신러닝 모델이 아닌 **설명 가능한 규칙 기반 접근성
모델**을 사용합니다.

1. 현재 위치가 있으면 현재 위치, 없으면 테스트 위치를 기준으로
   충전소 직선거리 계산
2. 충전소 ID, 시설명·주소, 좌표 순으로 공공데이터 context 매칭
3. 거리, 정보 완성도, 횡단보도, 경사 안전성, 이용 편의성 평가
4. 다섯 항목을 합산해 100점 접근성 점수 산출
5. 점수에 따라 적극 추천, 이용 추천, 확인 후 이용, 이용 전 주의 분류
6. 평가 결과를 항목별 점수와 추천 사유로 사용자에게 설명

향후 사용자 선택과 현장 신고 데이터가 충분히 축적되면 규칙 기반
모델을 개인화된 머신러닝 추천으로 고도화할 수 있습니다.

## 6. 차별성

### 위치 안내에서 선택 지원으로

단순히 충전소 위치를 나열하지 않고, 전동휠체어 이동 관점에서 비교할
수 있는 접근성 점수와 추천 등급을 제공합니다.

### 서로 다른 공공데이터의 결합

충전소, 횡단보도, DEM 데이터를 충전소 단위 context로 결합해 개별
데이터를 실제 의사결정 정보로 전환합니다.

### 설명 가능한 추천

최종 점수만 보여주지 않고 거리 30점, 충전소 정보 20점, 횡단보도
20점, 경사 안전성 20점, 이용 편의성 10점의 breakdown과 추천 사유를
제공합니다.

### 장애 상황을 고려한 서비스 구조

FastAPI 서버 연결에 실패해도 앱에 포함된 로컬 JSON을 이용해
충전소 탐색과 기본 접근성 기능을 유지합니다.

## 7. 기대효과

- 전동휠체어 이용자의 충전소 탐색 시간과 충전 불안 감소
- 이동 전 횡단 환경과 경사 부담을 확인해 선택권 향상
- 공공 충전 인프라의 실질적 접근성 향상
- 지자체가 충전소 정보 품질과 입지를 개선할 때 참고 가능한 근거 제공
- 분산된 공공데이터의 이동약자 서비스 활용 사례 제시

## 8. 현재 구현 범위와 한계

### 현재 구현

- 군산시 충전소, 횡단보도, DEM 고도·경사 데이터
- 규칙 기반 통합 100점 접근성 점수
- 지도, TOP 5, 상세정보, 횡단보도 레이어
- 위치 확인용 직선 연결
- 서버 및 로컬 fallback

### 현재 미구현

- 실제 보행 경로 탐색과 음성 길안내
- 실시간 공사·장애물·노면 상태 반영
- 보호구역, 장애인 편의시설, 기상 데이터 연동
- 사용자 신고·리뷰
- 머신러닝 기반 개인화 추천

## 9. 확장 가능성

### 지역 확장

- 군산시에서 전북 전역으로 확대
- 데이터 표준화를 통한 전국 서비스 확장

### 데이터 확장

- 보행자도로, 인도 폭, 보도 단절
- 보호구역과 장애인 편의시설
- 기상청 단기예보
- 사용자 신고와 이용 후기

### 기능·모델 확장

- 실제 보행 경로 API 연동
- 위험 구간 회피 및 예상 이동시간 제공
- 이용자별 이동 특성을 반영한 개인화
- 축적 데이터 기반 AI 추천 모델 고도화

## 10. 핵심 메시지

> WheelCharge는 충전소의 위치를 보여주는 앱을 넘어, 전동휠체어
> 이용자가 공공데이터를 근거로 더 적합한 충전소를 선택하도록 돕는
> 접근성 의사결정 서비스입니다.
