# WheelCharge 발표 멘트

## 1. 30초 소개

“WheelCharge는 전동휠체어 이용자가 군산시 내 충전소를 쉽게 찾고,
이동 전 접근 가능성을 함께 판단하도록 돕는 공공데이터 기반 서비스입니다.
단순히 가까운 충전소를 보여주는 것이 아니라 거리, 충전소 정보,
주변 횡단보도와 보도턱 낮춤 정보, 경사도와 고도를 함께 반영해
100점 만점의 접근성 점수와 추천 등급을 제공합니다. 추천 근거도
항목별 점수와 문장으로 확인할 수 있습니다.”

## 2. 1분 기능 설명

“WheelCharge는 군산시 전동휠체어 충전소를 Kakao Map에 표시하고,
현재 위치를 기준으로 가까운 충전소 다섯 곳을 추천합니다. 사용자가
추천 카드를 선택하면 지도가 해당 충전소로 이동하고 마커가 강조되며,
시설명, 주소, 설치 위치, 문의처 같은 기본 정보를 확인할 수 있습니다.

여기에 전북특별자치도 횡단보도 데이터와 브이월드 DEM 기반 고도·경사
데이터를 충전소별로 결합했습니다. 주변 횡단보도, 보도턱 낮춤,
점자블록, 보행자신호와 경사 위험도를 통합 100점 접근성 점수에
반영하고, 항목별 점수와 추천 사유를 함께 제공합니다.

지도에서는 횡단보도 위치를 선택적으로 확인할 수 있고, 현재 위치와
선택 충전소 사이의 직선거리도 시각화합니다. 이 선은 실제 보행
경로가 아닌 위치 확인용 직선 연결입니다. 서버 장애 시에는 앱에
포함된 로컬 JSON을 사용해 기본 기능을 유지합니다.”

## 3. 접근성 점수 설명

“접근성 점수는 거리 접근성 30점, 충전소 정보 완성도 20점, 횡단보도
접근성 20점, 경사도·고도 안전성 20점, 이용 편의성 10점으로
구성했습니다. 별도의 기본 점수나 공공데이터 보너스를 더하지 않고
다섯 항목의 합계가 그대로 최종 점수가 됩니다.

85점 이상은 적극 추천, 70점 이상은 이용 추천, 55점 이상은 확인 후
이용, 55점 미만은 이용 전 주의로 구분합니다. 이 점수는 절대적인
안전 보장이 아니라 이용자가 충전소를 비교하고 이동 전에 확인할
사항을 파악하도록 돕는 규칙 기반 참고 지표입니다.”

## 4. 공공데이터 활용 설명

“횡단보도 원본 데이터에서 군산시 3,989건을 추출하고, 보행자신호,
보도턱 낮춤, 점자블록 정보를 정규화했습니다. 이후 각 충전소 주변의
횡단보도 개수와 최근접 거리, 관련 시설 개수를 계산했습니다.

브이월드 DEM 데이터에서는 각 충전소의 고도를 샘플링하고 주변 셀의
고도차로 경사 위험도를 추정했습니다. 이렇게 서로 다른 데이터를
충전소 단위의 context로 결합해 앱의 점수와 상세정보에 활용했습니다.”

## 5. 보행자전용도로 제외 설명

“보행자전용도로 데이터도 국토교통부 도시계획정보 SHP를 대상으로
가용성을 검토했습니다. 다만 군산시 행정코드 기준 제공분이 확인되지
않아 다른 지역 데이터를 임의로 사용하지 않고 이번 MVP의 앱 UI와
점수에서는 제외했습니다. 이는 데이터 가용성 검토에 따른 범위
결정이며, 향후 보행자도로, 인도 폭, 보도 단절 정보가 추가 개방되면
접근성 모델에 확장할 수 있습니다.”

## 6. 향후 확장 설명

“향후에는 실제 보행 경로 API를 연동해 직선거리를 경로 거리와 위험
구간 정보로 고도화할 계획입니다. 보호구역, 장애인 편의시설,
기상청 단기예보, 사용자 신고와 리뷰 데이터도 단계적으로 결합할 수
있습니다. 데이터가 충분히 축적되면 사용자의 이동 특성과 선호를
반영하는 머신러닝 기반 AI 추천 모델로 확장할 수 있습니다.”

## 7. 질문 대응용 짧은 답변

### 왜 단순 거리순 추천이 아닌가요?

“전동휠체어 이용자에게는 같은 거리라도 횡단 환경과 경사, 충전소
정보의 충분성에 따라 실제 이동 부담이 달라질 수 있기 때문입니다.”

### 이 점수가 안전을 보장하나요?

“아닙니다. 공공데이터 기반의 비교·참고 지표이며 현장 상황 확인을
대체하지 않습니다.”

### AI 모델이 적용됐나요?

“현재 MVP는 설명 가능한 규칙 기반 모델입니다. 사용자 데이터가
충분히 축적되면 개인화 AI 추천으로 고도화할 계획입니다.”

### 왜 실제 길찾기를 제공하지 않나요?

“현재 단계는 공공데이터 결합과 추천 가능성 검증에 집중했습니다.
앱의 경로 표시는 위치 확인용 직선 연결이며 실제 보행 경로 API는
향후 확장 항목입니다.”

### 서버가 중단되면 사용할 수 없나요?

“충전소와 접근성 공공데이터를 앱 assets에도 포함해 서버 연결 실패
시 로컬 JSON으로 기본 기능을 유지합니다.”

## 8. 마무리 멘트

“WheelCharge는 충전소 위치 데이터를 이동약자의 선택을 돕는 접근성
정보로 전환합니다. 향후 실제 경로와 현장 데이터를 결합해 더 안전하고
개인화된 이동 지원 서비스로 발전시키겠습니다.”
