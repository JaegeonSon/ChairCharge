# WheelCharge 발표 시연 시나리오

## 1. 시연 목표

약 3분 안에 다음 네 가지를 보여주는 것을 목표로 합니다.

1. 단순 위치 안내가 아닌 접근성 기반 충전소 추천
2. 횡단보도와 경사도·고도 공공데이터 활용
3. 점수 breakdown과 추천 사유를 통한 설명 가능한 추천
4. 서버 장애 상황에서도 유지되는 기본 기능

## 2. 시연 전 준비

- Android 기기 또는 에뮬레이터에서 위치 권한 허용
- FastAPI 서버 실행 및 단말과 같은 네트워크 연결
- 지도와 서버 데이터가 정상 로드되는지 사전 확인
- 시연할 충전소 한 곳과 예상 점수 미리 확인
- 횡단보도 레이어는 처음에 OFF로 설정
- 서버 fallback 시연 전 로컬 assets가 포함된 APK인지 확인

네트워크 상황이 불안정하면 서버 fallback 시연은 마지막에 설명 중심으로
진행하고, 앱의 핵심 추천 흐름을 우선 보여줍니다.

## 3. 권장 시연 흐름

| 순서 | 화면 조작 | 설명 포인트 |
|---:|---|---|
| 1 | 앱 실행 | 군산시 충전소 마커와 현재 위치 확인 |
| 2 | 하단 패널 펼치기 | 지도 중심 UI와 주요 기능 소개 |
| 3 | 우측 상단 현재 위치 아이콘 선택 | 현재 위치 재측정 및 가까운 충전소 탐색 |
| 4 | TOP 5 카드 확인 | 거리뿐 아니라 접근성 점수와 추천 등급 제공 |
| 5 | 추천 충전소 카드 선택 | 지도 이동, 선택 마커 강조, 상세 패널 연동 |
| 6 | 점수 구성 확인 | 다섯 항목의 점수 합계로 추천 근거 설명 |
| 7 | 공공데이터 정보 확인 | 횡단보도, 보도턱, 점자블록, 신호, 고도, 경사 확인 |
| 8 | 경로 보기 선택 | TMAP 계단 제외 우선 경로 또는 직선 fallback 표시 |
| 9 | 우측 상단 횡단보도 아이콘 ON/OFF | 주변 횡단보도 데이터 시각화 |
| 10 | 서버 fallback 설명 또는 시연 | 서버가 없어도 로컬 JSON으로 기본 기능 유지 |

지도 우측 상단에는 현재 위치 재측정과 횡단보도 레이어 버튼이 세로로
배치됩니다. 하단 패널은 `추천 상태 → 추천 충전소 TOP 5 → 선택 충전소
상세정보` 순서로 확인합니다. 상세정보 안에서는 접근성 점수와 추천 등급,
경로 버튼, 기본정보, 점수 구성, 추천 이유, 공공데이터 근거가 차례로
표시됩니다. 경로 표시 전에는 `경로 보기`, 표시 중에는 `경로 숨기기`
버튼 하나만 노출됩니다.

## 4. 단계별 발표 멘트

### 1단계: 앱 실행

“앱을 실행하면 군산시 전동휠체어 충전소가 지도에 표시되고, 위치
권한이 허용된 경우 현재 위치가 파란 점으로 표시됩니다.”

### 2단계: 현재 위치 추천

“우측 상단 현재 위치 아이콘을 선택하면 위치를 다시 측정하고 가까운
충전소 다섯 곳을 보여줍니다.
단순 거리 순위와 함께 전동휠체어 이용 관점의 접근성 점수와 추천
등급을 제공합니다.”

현재 위치를 가져오지 못한 경우:

“위치 정보를 사용할 수 없는 상황에는 군산시청 인근 테스트 위치를
기준으로 같은 추천 기능을 확인할 수 있습니다.”

### 3단계: 충전소 선택

“TOP 5 카드를 선택하면 해당 충전소로 지도가 이동하고 마커가 강조되며,
마커를 직접 선택했을 때와 같은 상세정보가 표시됩니다.”

### 4단계: 접근성 점수

“점수는 거리 30점, 충전소 정보 20점, 횡단보도 20점, 경사 안전성
20점, 이용 편의성 10점으로 구성됩니다. 항목별 점수를 그대로
보여주기 때문에 추천 결과의 근거를 설명할 수 있습니다.”

### 5단계: 공공데이터

“이 충전소 주변의 횡단보도 개수와 최근접 거리뿐 아니라 보도턱 낮춤,
점자블록, 보행자신호를 확인할 수 있습니다. 브이월드 DEM으로 산출한
고도와 경사 위험도도 함께 제공합니다.”

### 6단계: 경로 표시

“경로 보기는 TMAP 보행자 경로 API로 계단 제외 우선 경로를 탐색합니다.
API 호출에 실패하거나 경로가 없으면 현재 위치와 충전소 사이의 위치
확인용 직선 경로로 자동 전환됩니다.”

### 7단계: 횡단보도 레이어

“우측 상단 횡단보도 아이콘을 켜면 선택 충전소 주변의 횡단보도를 확인할
수 있습니다. 지도 성능을 고려해 기본값은 OFF이고 주변 데이터만
제한적으로 표시합니다.”

### 8단계: 서버 fallback

“서버 연결이 실패해도 앱에 포함된 로컬 JSON으로 충전소, 추천,
상세정보와 공공데이터 기반 점수를 계속 확인할 수 있습니다.”

## 5. 시연 중 강조할 문장

- “가장 가까운 곳이 항상 가장 접근하기 쉬운 곳은 아닙니다.”
- “추천 결과를 점수 구성과 문장으로 설명할 수 있습니다.”
- “확보 가능한 공공데이터를 충전소 단위의 의사결정 정보로 바꿨습니다.”
- “서버 장애 상황에서도 사용자가 기본 정보를 확인할 수 있습니다.”

## 6. 시연 시 주의사항

- TMAP 실패 시 표시되는 직선 Polyline을 실제 보행 경로라고 설명하지 않습니다.
- 점수를 절대적인 안전 점수나 현장 안전 보장으로 표현하지 않습니다.
- 머신러닝 기반 AI 추천이 구현되었다고 설명하지 않습니다.
- 보호구역, 편의시설, 기상 데이터가 현재 반영되었다고 설명하지
  않습니다.
- 보행자전용도로는 데이터 가용성 검토 결과 MVP에서 제외했다고
  설명합니다.

## 7. 오류 발생 시 대체 흐름

- 현재 위치 실패: 테스트 위치 추천으로 전환
- 서버 연결 실패: 로컬 JSON fallback 동작을 기능으로 설명
- 횡단보도 레이어 지연: 상세정보의 집계값과 점수 breakdown 중심으로 진행
- 지도 네트워크 지연: TOP 5 카드, 상세정보, 점수 설명을 우선 진행

## 8. 종료 멘트

“WheelCharge는 충전소가 어디에 있는지를 넘어, 전동휠체어 이용자가
어느 충전소를 선택할지 판단할 수 있는 접근성 정보를 제공합니다.”
